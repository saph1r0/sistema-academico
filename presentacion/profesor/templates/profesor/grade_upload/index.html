Instrucciones para Subir Notas

Formato del Archivo Excel

  • Usar la plantilla "Excel notas P1" descargada del sistema
  • Completar columnas: código estudiante, nota parcial, nota continua
  • Notas deben estar entre 0.00 y 20.00
  • No modificar códigos de estudiante

Proceso de Subida

  1. 1 Seleccionar curso y fase académica
  2. 2 Descargar plantilla Excel específica del curso
  3. 3 Completar notas en la plantilla
  4. 4 Subir archivo usando el botón "Subir Excel de Notas"
